# Training Farm R0.4 — deterministic savestate fork primitive

R0.4 adds a **single-process** deterministic fork primitive on top of the existing R0.2/R0.3 Stable-Retro + FBNeo adapter. It restores one authoritative root savestate before every branch repetition, executes an explicit all-player frame-input sequence, and records compact hash evidence only.

It does not add multi-worker orchestration, Reward, route/search policy, RL, gameplay semantics, or Browser/WinKawaks address assumptions.

## Contracts

- plan schema: `training/farm/savestate_fork_plan.schema.json`
- result schema: `training/farm/savestate_fork_result.schema.json`
- fixture plan: `training/farm/savestate_fork_plan.example.json`
- CLI: `python -m training.farm.savestate_fork`

Every branch has a stable `branchId`, exact `horizonFrames`, canonical R0.2 full-frame actions, action-sequence SHA-256, and branch execution identity. `metadata.label` is human-only and is not execution authority. Branch execution order is canonicalized by `branchId`.

## Root authority and isolation

The root binds:

- `sourceNamespace = stable-retro-fbneo`;
- root savestate SHA-256;
- flat RAM SHA-256 and address-aware RAM-block snapshot SHA-256;
- exact Stable-Retro memory-block layout identity;
- runtime / ROM / backend / R0.2 Farm candidate identity;
- R0.4 source-file candidate identity;
- fork-set/root ids and logical root frame `0`.

Before every branch repetition, R0.4 loads the exact root, verifies restored RAM/layout and save/load roundtrip, verifies runtime/source identity, then executes only explicit four-player frame masks. No branch is allowed to inherit the terminal emulator state or input mask of another branch.

## Deterministic replay

Each branch is replayed 2–10 times (3 in the example). A branch passes only when all required repetitions match on bounded frame checkpoints plus final flat RAM, address-aware RAM blocks, and final savestate hash. Up to 64 deterministic checkpoints are retained per branch repetition. The first known divergence is reported when possible.

A fork-set `PASS` requires every required branch to be present and `PASS`. Missing, failed, drifted, or partial branches never become a successful fork-set.

## Partial / resume

`--max-new-branches` provides an intentional bounded partial execution path. `KeyboardInterrupt` also retains already completed branch metadata. A partial result is resumable only after strict validation of the same fork plan, root savestate/RAM/layout, ROM/runtime/backend/Farm source authority, R0.4 source authority, branch/action identities, repetition count, checkpoints, and outcome fingerprints.

Only already-complete deterministic `PASS` branches are reused. Tampered, duplicated, unknown, stale, or differently bound branch evidence fails closed. Cross-process resume permits only the existing run-local `processId` difference; all durable runtime/ROM/source/backend authority remains identical.

## Fixture CLI

Full ROM-free implementation run:

```bash
python -m training.farm.savestate_fork \
  --fake \
  --plan training/farm/savestate_fork_plan.example.json \
  --output /tmp/r0.4-fork.json
```

Intentional partial run (returns exit code `3`):

```bash
python -m training.farm.savestate_fork \
  --fake \
  --plan training/farm/savestate_fork_plan.example.json \
  --max-new-branches 1 \
  --output /tmp/r0.4-partial.json
```

Resume it:

```bash
python -m training.farm.savestate_fork \
  --fake \
  --plan training/farm/savestate_fork_plan.example.json \
  --resume /tmp/r0.4-partial.json \
  --output /tmp/r0.4-resumed.json
```

Fixture results use `proofScope = IMPLEMENTATION_FIXTURE` and always keep `realWofProof = false`.

## Real runtime gate

A real fork proof is allowed only when the legal local Stable-Retro/FBNeo runtime is ready **and** a matching current-source R0.2 real-WOF determinism proof is accepted by the existing R0.3 consumer gate.

```bash
python -m training.farm.savestate_fork \
  --plan /path/to/fork-plan.json \
  --r0-2-proof /path/to/current-r0.2-real-proof.json \
  --root-state /path/to/local-root.state \
  --output /path/to/local-r0.4-result.json
```

`--root-state` is optional; when omitted, the command captures a reset root. ROM and savestate bytes stay local and are never serialized into the result JSON or repository. A missing legal runtime produces structured `SKIP`; a missing/rejected current R0.2 proof cannot become real-WOF fork proof.
