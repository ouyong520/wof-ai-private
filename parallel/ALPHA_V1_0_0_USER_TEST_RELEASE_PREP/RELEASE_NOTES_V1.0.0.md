# WOF Future Danger Alpha V1.0.0 — 玩家测试版说明

> **状态：NOT RELEASED**  
> 这是 V1.0.0 的用户视角 release-notes 准备稿，不代表已经发布。最终 Browser/WOF non-drift 动态证明以及当前全部 P0/P1 release gates 通过后，才能生成并宣布正式玩家测试包。

## V1.0.0 想解决什么

这是第一版面向真实玩家的“可信实时危险提示”基线。重点不是把功能堆得很多，而是让已经支持的提示尽量挂在正确对象上；一旦位置不可信，就宁可隐藏或退回 fixed HUD，也不要自信地显示在错误位置。

## 玩家能看到的主要功能

- **玩家头顶危险提醒**：当当前已验证的危险规则命中某个玩家时，提醒应出现在正确的 P1 / P2 / P3 玩家附近并跟随移动。
- **怪物头顶目标标签**：受支持怪物显示当前锁定的 `1P` / `2P` / `3P`。
- **实时改锁**：怪物目标变化后，旧目标标签/旧玩家提醒不应继续残留。
- **运动跟随**：V1.0.0 的发布验收覆盖左右移动、纵深移动、跳跃、快速推进和镜头/整屏卷动。
- **resize / fullscreen 适配**：窗口尺寸或全屏状态变化后，覆盖层不能继续沿用旧的屏幕映射。
- **fail-closed 显示**：定位依据不新鲜、不完整或不可信时，头顶提示可以隐藏，危险提醒可以退回 fixed HUD。
- **只读辅助**：本版本不替玩家操作游戏，不修改敌人目标，不写游戏 RAM。

## 已知限制

- V1.0.0 **不是全攻击覆盖版**。只有当前已经验证、允许进入生产提示范围的危险状态才会提示；没有提示不等于“场面一定安全”。
- V1.0.0 **不提供移动路线或躲避方向**，也没有自动移动、自动攻击、自动闪避等输入控制。
- V1.0.0 **不承诺 0 伤或通关能力**。
- 某些时刻如果系统不能可靠判断屏幕位置，玩家头顶提醒可能暂时消失或退回 fixed HUD；这是安全降级，不应被当成漂移 bug。
- 反过来，如果提示持续跟错玩家、跟错怪物、停在旧屏幕位置，或者改锁后残留旧标签，则属于需要反馈的问题。
- 支持范围以最终 V1.0.0 测试包内经过门禁验证的版本为准；本准备稿不会提前锁定最终 commit、package hash 或 projection 参数。

## 首次测试建议

第一次拿到正式测试包，优先用 3–5 分钟验证最容易看到的问题：

左右移动 → 纵深移动 → 跳跃 → 快速推进/卷屏 → 观察 `1P/2P/3P` 与自然 retarget → 做一次 resize/fullscreen。

详细步骤见同目录 `README.md`。

## 后续 V1.x 方向

V1.0.0 稳定以后，后续补丁优先做玩家能直接感觉到的改善，例如：

- 危险提醒更容易看清；
- 多怪场景更容易读懂谁在锁谁；
- 在证据足够的前提下扩大实用危险覆盖；
- 继续降低复杂运动和场景切换中的视觉噪声。

内部重构、QA、工具或采集工作本身不会因为“做完了”就单独升级一个用户版本号；只有玩家体验真的变好、并且安全门禁通过，才进入 V1.0.1 / V1.0.2 等后续版本。

## 发布门禁

V1.0.0 只有在以下条件全部满足后才可以从 `NOT RELEASED` 改为玩家测试发布：

1. 当前 P0/P1 release gates 全部关闭；
2. 当前 release snapshot 的 Browser/WOF bounded live acceptance 通过；
3. 玩家头顶危险提醒和怪物头顶目标标签完成真实动态 non-drift 验证；
4. retarget、快速移动/跳跃/卷屏、resize/fullscreen 等关键场景没有可重复的明显漂移或错误绑定；
5. 最终 one-click package 在这些上游状态稳定后重新生成并通过其自身门禁。

在此之前：**NOT RELEASED**。
