# WOF Future Danger Alpha V1.0.0 — 玩家首测入口

> **当前状态：NOT RELEASED（发布准备稿）**  
> 这份说明已经按玩家视角准备好，但 **V1.0.0 还没有宣布发布**。只有最终 Browser/WOF 动态 non-drift 证明和当前全部 P0/P1 release gates 通过后，才可以把正式测试包交给玩家。

## 你只需要记住一个入口

拿到最终 V1.0.0 玩家测试包后：

**双击包根目录的 `WOF_一键工具.cmd`。**

不要单独运行 Recorder、PYLAUNCH、Transport、HUDANCHOR 或任何开发脚本，也不需要打开 DevTools、粘贴 JavaScript、查看内存地址。

一键工具打开中文界面后，按现有菜单提示启动游戏辅助，然后正常进入 WOF 游戏即可。测试时只需要看游戏画面上的提示是否正确。

## 正常情况下你应该看到什么

V1.0.0 首测只关注三件事：

1. **玩家头顶危险提醒**：当当前已支持、已验证的危险状态命中某个玩家时，危险提醒应跟在正确的 P1 / P2 / P3 玩家头顶。
2. **怪物头顶目标标签**：受支持的怪物会显示当前锁定目标 `1P` / `2P` / `3P`；怪物改锁时，旧标签应立即被新标签替换。
3. **fixed HUD fallback**：如果系统暂时不能可靠确定头顶位置，提醒可以隐藏或退回 fixed HUD。这个降级是允许的；**明显漂移、挂错玩家、挂错怪物、改锁后还留在旧目标上，不是允许行为。**

## 3–5 分钟首测

按正常游戏方式完成即可，不需要故意制造特殊状态：

1. **左右移动（约 30 秒）**：让玩家快速左右移动，观察玩家头顶提醒和怪物头顶标签是否仍跟着正确对象。
2. **上下 / 纵深移动（约 30 秒）**：在场景深度方向移动，观察提示是否明显飘离角色/怪物。
3. **跳跃（约 30 秒）**：完成几次跳跃，覆盖起跳、最高点、下落、落地。
4. **快速推进 / 卷屏（约 60 秒）**：快速向前推进，尽量触发明显的镜头或整屏滚动；任何提示都不应停留在旧屏幕位置。
5. **观察怪物目标与 retarget（约 60 秒）**：看到 `1P / 2P / 3P` 标签时确认目标正确；如果自然发生改锁，确认标签和危险提醒同步切换，不残留旧目标。
6. **resize / fullscreen（约 30 秒）**：在测试环境允许时做一次窗口尺寸变化或窗口/全屏切换，随后继续移动，确认提示没有整体错位。

多人或多怪场景如果自然出现，可以顺便观察，但首测不要求为了凑场景长时间等待。

## 怎么判断“正常”

正常：

- 提示跟着正确的玩家/怪物；
- 快速移动、跳跃、卷屏后没有明显残影或持续漂移；
- 改锁后旧目标上的提示立即消失/切换；
- 定位不确定时提示隐藏或退回 fixed HUD；
- 游戏本身继续正常运行。

需要反馈：

- 提示明显飘在角色/怪物旁边并持续跟错位置；
- 危险提醒挂到错误玩家；
- `1P / 2P / 3P` 显示了错误目标；
- 改锁后旧标签/旧玩家提醒仍残留；
- resize/fullscreen 后提示整体错位；
- 本应有提示时长期没有任何提示，且不是短暂 fallback/隐藏。

## 反馈方式

优先直接复制 `BUG反馈模板.md`，只写你看到的现象和当时场景。能顺手截一张图或录一小段视频最好；没有也可以反馈。

不要为了反馈去找内存地址、开发日志、Console 或工程文件。只有后续排查确实需要时，项目方才会单独说明。

## 当前 V1.0.0 范围

V1.0.0 是可信实时提醒的第一版，不承诺所有攻击都能识别，也不提供移动路线、自动躲避、自动操作或“0 伤通关”。这些不属于本次玩家首测标准。

完整用户视角版本说明见 `RELEASE_NOTES_V1.0.0.md`。
